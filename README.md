# 拾光塔罗 · Shiguang Tarot

一个无需安装、无需注册的浏览器塔罗牌小游戏。使用 HTML、CSS 和 JavaScript 编写，牌面图案由 Canvas 绘制，无远程资源和第三方运行时依赖。

## 功能

- 78 张牌：22 张大阿尔卡那与四组小阿尔卡那。
- 三张牌阵：现状、阻碍、建议。
- 五张牌阵：现状、阻碍、潜在影响、助力、下一步。
- 可切换正逆位，揭晓前可以取消或更换选择。
- 洗牌后牌序固定，按选择顺序揭晓。
- 复制牌阵结果，并提供手动复制方式。
- 自动保存当前问题和进度，支持刷新恢复和清除本地记录。
- 适配手机屏幕、系统深浅色模式与减少动态效果偏好。

## 运行

下载项目后，用现代浏览器打开 `index.html` 即可。将 HTML、CSS 和 JavaScript 三个文件保存在同一目录。

也可以在项目目录启动静态服务器：

```sh
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 使用

1. 选择三张或五张牌，按需填写问题并设置是否包含逆位。
2. 从牌堆中选牌，再次点击可以取消选择。
3. 选齐后点击“揭晓”，查看牌面及对应牌位。
4. 点击“复制本次结果”保存文字记录，或重新洗牌开始下一轮。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构与资源引用 |
| `styles.css` | 页面、牌面、主题与响应式样式 |
| `app.js` | 牌堆、洗牌、交互、绘图与进度保存 |

## 本地数据

问题和牌阵保存在当前浏览器的 `localStorage` 中，程序不发送或上传这些内容。点击“清除本地进度”可以删除本项目保存的记录。无痕模式、浏览器存储限制、移动文件或清理站点数据可能影响保存；浏览器无法保存时会显示提示。

本项目仅用于娱乐与自我探索，不作确定预言。
